# typst-nor-letter
A Typst business document/letter template conforming to the NS 4129:1995 standard for Norwegian documents (Kontordokumenter og blanketter - Utforming). This standard references ISO 6422:1985 (Layout key for trade documents).

## Background
The project goal is to create a template that will output professional-looking documents with room for a complete set of standard metadata such as dates, archive references, recipients, document type / form and more. At the same time, the document should conform to official standards as far as they exist. This is why NS 4129 is chosen as the reference point - it is far from perfect from a design perspective, but it is the only authoritative source for the layout of this type of document.

NS-4129 is not publicly available, but you may be able to view a copy from your local library either physically or online.

This norm is very much a product of the early 1990s, at a time when the authors for example seemed to think that X.400 mail addresses were important to include and SMTP email was far from dominating. Correct and uniform placement of all elements was also more important when office workers frequently relied on pre-printed forms and templates of various types. Even so, the norm still works very well, especially in situations where there is a complete set of metadata. Complex sets of contact details including postal and physical addresses, multiple phone numbers, registry numbers and bank details print cleanly in the footer without cluttering the documents.
